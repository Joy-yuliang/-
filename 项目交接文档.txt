## 一、项目是什么（30 秒版）

**个人生活体系软件**：一个运行在 Windows 11（联想笔记本）上的**独立桌面应用**，是用户的「个人操作系统」——把生活计划（每日 SOP）、日记（历史与成长记录）、体系（分门别类的知识/方法论树）、日程、全局搜索整合在一个本地软件里，纯本地存储、可导出到 WPS、可不断迭代。

核心页面（顶栏页签）：**计划 / 日记 / 体系 / 设置**，外加**全局搜索 🔍**。

## 二、核心理念与需求来源（用户原话提炼）

- **体系 = 思维和行为的底层逻辑**。没有体系做事没章法；有体系努力才能积累、乘复利向上。
- 软件是「体系」的**执行层**：体系是底层逻辑，软件让体系落地。
- 体系需要**自我修正和发展迭代**；软件本身也要可被持续优化调整，吸纳一切优秀的思想资源。
- **层级定位（重要）**：用户强调——每日 SOP 不是总体系，而是**三级体系**：总体系（一级）→ 生活的相关问题（二级）→ **生活的基本方面（三级）**。软件的分类必须支持任意深度（学习→英语学习→四级/六级/考研/雅思→四级单词…）。

### 每日 SOP（计划页的设计蓝本，用户确认）
8 步固定轨道：
1. 唤醒：起床、穿裤子、打开窗帘、喝一口水或上厕所（①②③约半小时）
2. 看安排：不看手机（抖音/朋友圈/游戏），打开软件看今天的安排
3. 洗漱护肤：涂该涂的，需要时涂防晒
4. 按当天安排开始活动
5. 固定读书：不少于 1 小时（书/微信文章等）
6. 晚间总结：写日记、感悟、总结反思；检验例行公事和计划完成情况；未完成如实记录原因，第二天纠正
7. 睡前：刷牙洗脸，涂该涂的
8. 睡觉：12 点左右必须睡

SOP 原则（需软件化）：
- **流程不可打乱**：计划只能安排在流程之中，不能因沉迷一件事跳过基本环节；
- **不心血来潮**：不做没安排的事（紧急事务除外，事后须纠正记录）；
- **临时起意机制**：有想法→及时记录→小事先做掉/做一点→剩下的复制到第二天计划（临时起意本身是流程的一部分）；
- **安排不要太满**：保证每件事做好做对，关键重要紧急优先；
- **硬约束**：23:00 必须开始总结，24:00 必须睡觉（无论做完没有）。

## 四、当前版本功能清单（v0.5）

### 计划页
- 顶部：日期切换（‹ ›）、**点击日期弹出小日历选日期**、「📅 日历」按钮（日程大日历）、回到今天、今日完成进度条、「导出安排」
- **例行公事**：8 步 SOP 每天自动出现，打 ✓ 完成、点 ✗ 标记未完成并记录原因（设置里可增删改排序）
- **栏目**：安排（清单，**点条目文字可修改**，未完成 ✗ 记原因）、读书（内容+感受+时长）、临时起意（**复制→明天**，今天记录保留）、总结（可展开）
- **次日计划**：今晚规划明天
- **总结 / 次日计划文字框**：右下角 ⤢ 展开图标 → 大编辑框（**编辑/预览** 页签 + **⟲撤销/⟳恢复**）
- **📅 日程日历**：大日历弹窗（« ‹ › » 翻年翻月、显示农历/节日），点某天右侧看日程；「＋ 添加日程」= 名称、开始时间、结束时间、地点、备注；有日程的天显示**红色「有日」**；可删除

### 日记页（v0.5 改版）
- 整页日记区（无左侧大日历）：上方 = **时间（可点击弹日历）+ 今日音乐 + 天气**；下方 = **事件、情绪、思考、随笔** 四分区
- 每个写字框右下角 ⤢ 图标 → 大编辑框（编辑/预览 + 撤销/恢复）
- 日期自动给出：年月日 + 星期 + 节日/节气（农历库 lunar-javascript，覆盖劳动节/春节/中秋等）
- 「导出日记」→ Word 文档

### 体系页 ⭐（核心）
- **体系建构**（便签视图）：「＋ 新增一级体系」→ 卡片显示**层级标签/标题/字数/更新时间/子体系数量**；**点击整条任意位置展开/收起**；展开后显示内容 + 「＋ 新增二级/三级/…体系」（**支持到十六级**）
- 内容**支持 Markdown**（编辑/预览切换），输入框大而舒适
- 每卡片：**编辑 / 移动**（移到任意体系或顶层）/ **删除**（连同子体系，需确认）
- **总体预览**（树状图）：从"体系"延伸，**点开一级→展开二级，点开二级→展开三级**；点节点右侧看内容（后续计划支持多种图式切换）
- 页面常驻挂载：切页签编辑状态不丢失

### 设置页
- 每日 SOP 步骤增删改排序；栏目管理（新增/改名/删除）；提醒开关与时间（23:00 总结、24:00 睡觉）

### 全局搜索 🔍
- 顶栏放大镜 → 搜索框，全局搜**计划/日记/体系**；结果带标签（计划=蓝/日记=绿/体系=橙）+ 日期或体系名，命中文字黄色高亮
- 点击结果 → **跳转到对应位置**（切页签、定位闪烁；体系自动展开到目标层级路径），右下角出现**「← 返回搜索」**
- 点返回键或随便点一下内容（开始编辑）→ 返回键消失；**搜索框文字和结果一直保留**，可反复跳转

## 五、技术架构与文件位置

### 技术栈
| 组件 | 选型 |
|---|---|
| 桌面外壳 | Electron 33（Chromium + Node） |
| 界面 | React 18 + Vite 5（JSX，无 TypeScript） |
| 数据存储 | **JSON 单文件**（`%APPDATA%\个人体系\data\tixi-data.json`），纯本地，备份该文件即可 |
| Markdown | marked + dompurify |
| 农历/节日/节气 | lunar-javascript |
| Word 导出 | docx（生成 .docx，WPS 可打开） |
| 打包 | electron-builder（portable 单文件 exe，跳过签名） |

### 目录结构
```
C:\Users\lenovo\体系\

├── 架构设计.md           技术方案与进度
├── 使用说明.md           用户手册
├── 项目交接文档.md / .txt  ← 本文档
├── 启动个人体系.bat       开发启动（vite build && electron .）

    ├── index.html
```

### 数据模型（tixi-data.json）
```json
{
  "settings": { "remindersEnabled": true, "summaryReminder": "23:00", "sleepReminder": "00:00" },
  "columns": [ { "id", "name", "type": "checklist|reading|text", "sort" } ],
  "routines": [ { "id", "name", "sort" } ],        // 8 步 SOP
  "systems": [ { "id", "parentId", "title", "content", "createdAt", "updatedAt" } ], // parentId=null 为一级
  "events": { "2026-08-19": [ { "id", "name", "start", "end", "location", "notes" } ] },
  "days": { "2026-08-19": { "routine": {...}, "lists": { "colId": [ {id,text,status,reason} ] },
                            "reading": [ {id,content,feeling,minutes} ], "summary": "", "tomorrow": "",
                            "diary": { "music","weather","events","thoughts","mood","essays" } } }
}
```

### 常用命令（在 app 目录）
- `npm.cmd run build` → 构建界面
- `npm.cmd start` → 开发运行
- `npm.cmd run app` → 构建+运行
- `npm.cmd run dist` → 打包便携 exe 到 release\
- 打包产物：`app\release\个人体系.exe`；日常副本：`C:\Users\lenovo\体系\个人体系.exe`（桌面有快捷方式）

### 开发环境注意事项（如要继续开发）
- 本机 PowerShell 执行策略禁止 .ps1，npm 一律用 **`npm.cmd`**；
- npm 11 的 allow-scripts 机制：electron/esbuild 的安装脚本需先 `npm.cmd approve-scripts electron esbuild`；
- 国内网络：npm 用 `--registry=https://registry.npmmirror.com`，Electron 二进制用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，electron-builder 用 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`，缓存目录指到工作区内（如 `C:\Users\lenovo\体系\.npm-cache`）；
- 数据文件必须 UTF-8；
- 在 DSH 沙箱环境内构建/安装需完整访问权限（进程派生限制），用户本机直接运行不受影响。

## 七、对话纪要（按时间线浓缩）

1. **初始需求**（用户原话）：做一个生活体系软件，涵盖生活学习思考各方面；核心功能：①计划表格（安排/读书/临时起意/总结，打勾）②分门别类（大体系下小体系、相互交错）③抽取其他软件（WPS）的日记记录进行分析；"体系是杠杆，让努力乘复利"，"搭建体系不是一蹴而就"，希望不断交流完善需求后再开发。
2. **第一轮问答**：独立桌面应用 / 每日一页清单 / 栏目固定+可扩展 / 树状层级+交叉标签 / 要 AI 提炼 / 导入 docx+粘贴 / 纯本地 / 每天用+要复盘。
3. **用户提供每日 SOP**（见第二节），明确 23:00/24:00 硬约束、临时起意机制、流程不可打乱等原则。
4. **第二轮问答**：日记软件内写和 WPS 导入两处都写（按心情）；需要导出到 WPS（docx）；读书要有内容+感受记录栏；提醒要任务级灵活（截止/开始时间+提前N分钟）。
5. **层级纠正**：SOP 是三级体系（总体系→生活相关问题→生活的基本方面）；先做生活板块，其他体系在体系树上逐步长出。
6. **v0.1**：计划页 MVP（SOP 轨道+栏目+打勾+未完成原因+次日计划+临时起意+JSON 存储+导出安排 docx+23:00/24:00 提醒）。技术栈定 Electron+React+JSON。
7. **v0.2**：日记页（日历翻月翻年、农历/节日/节气、音乐/天气、事件/思考/情绪/随笔、导出日记 docx）。打包便携 exe + 桌面快捷方式，软件可直接双击打开。
8. **v0.3**：体系页（便签式多级体系+Markdown+体系树+移动/删除）。随后按反馈修复：编辑/移动按钮需先展开才能用的问题；页签改名（每日→**计划**、便签视图→**体系建构**、体系树→**总体预览**）；输入框放大两倍；卡片点击整条展开/收起；层级标签；四级及以上体系（支持到十六级）；编辑状态跨页签保留。
9. **v0.4**：时间可点选（计划/日记日期弹日历）；日程日历（名称/起止/地点/备注、红色"有日"、点击查看）；全局搜索（🔍放大镜、结果带标签、点击跳转+临时"返回"键、搜索状态保留）；清单条目点文字修改；临时起意改"复制→明天"（今天记录保留）。
10. **v0.5（当前）**：日记页改版（去掉左侧大日历、整页更宽敞；展开图标移到写字框右下角；展开编辑框加大+编辑/预览+撤销/恢复）；计划页总结/次日计划文字框同步升级；修复体系搜索跳转空白（tab 代号错误）与搜索结果条目显示（标签挤占内容）。
11. **本次**：用户要求把全部对话打包成交接文档，用于夸克网页版 DeepSeek 新对话继续协作。
