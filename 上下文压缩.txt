# 个人体系软件 · 上下文压缩包（当前版）

> 用途：把整个项目与全部对话要点压缩成一份可独立理解的上下文，供新对话/新环境快速接手。
> 生成：2026-08-21（当前版本 v0.7，已构建运行）。本文档刻意精简，需要细节时参考《需求文档.md》《架构设计.md》《使用说明.md》《项目交接文档.md》。

## 一、项目一句话

Windows 11 桌面应用「个人体系」= 用户的**个人操作系统**：计划（每日 SOP）+ 日记（历史与成长）+ 体系（方法论/知识树）+ 日程 + 全局搜索。纯本地 JSON 存储、可导出 WPS、可持续迭代。

## 二、核心理念（用户原话提炼）

- **体系 = 思维和行为的底层逻辑**；软件是体系（底层逻辑）的执行层。
- 体系须**自我修正、持续迭代**；软件须可被持续优化、吸纳一切优秀思想资源。
- **层级**：每日 SOP 是三级体系（总体系→生活相关问题→生活的基本方面）；分类支持任意深度（如 学习→英语学习→四级→四级单词）。
- 命名偏好：页签叫「计划」（不叫每日）；体系页用「体系建构」「总体预览」。

## 三、产品决策（已确认）

| 项 | 决策 |
|---|---|
| 形态 | 独立桌面应用，双击 exe 使用 |
| 计划 | 每日一页：SOP 轨道 + 栏目 + 打勾 + 未完成原因 + 次日计划 |
| 栏目 | 安排/读书/临时起意/总结，可增删改扩展 |

| 搜索 | 全局（计划/日记/体系）：小标签 + 整句 + 跳转 + 临时返回键 |
| 导出 | 当天安排 / 日记 → docx（WPS 可打开） |
| 存储 | 纯本地 JSON 单文件 |
| AI | 已确认要 DeepSeek 参与——**尚未接入**（路线图第一项） |

## 四、每日 SOP（计划页设计蓝本）

8 步：①唤醒 ②看安排（不看手机）③洗漱护肤 ④按安排活动 ⑤读书≥1h ⑥晚间总结（日记/反思/检验/次日计划）⑦睡前 ⑧24 点睡。
原则：**流程不可打乱**；不心血来潮；临时起意=随手记→小事先做→复制到明天（今天记录保留）；安排不要太满；23:00 开始总结 / 24:00 睡觉为硬约束。

## 五、当前功能清单（v0.7）

### 计划页
- 日期 ‹› + 点击弹日历；📅 日程大日历（＋添加日程：名称/开始/结束/地点/备注）；进度条；导出安排
- 例行公事：8 步自动生成，✓/✗ + 未完成原因（设置可改步骤）
- 安排/临时起意：点文字直接修改；✗ 记原因；「复制→明天」（今天保留）
- 读书：内容+感受+时长；总结/次日计划：⤢ 展开（编辑/预览 + 撤销/恢复）

### 日记页
- 吸顶栏（时间可点选弹日历 / 今日音乐 / 天气，无边框）；事件、情绪、思考、随笔各自独立卡片；选非今天出现「回到今天」；导出日记
- 每个写字框右下角 ⤢ → 接近全屏编辑框（编辑/预览 + ⟲撤销/⟳恢复）

### 体系页
- 体系建构：便签卡片（层级标签/标题/字数/更新时间/子体系数），点击整条展开/收起；「新增下一级」到十六级；内容支持 Markdown（编辑/预览）；编辑/移动/删除（删除级联需确认）；切页签编辑状态不丢失
- 总体预览：树状图，点开一级→展开二级→三级…；点节点右侧看内容

### 设置页
- 每日 SOP 步骤增删改排序；栏目管理（新增/改名/删除）；提醒（23:00 总结、24:00 睡觉，可开关可改时间）

### 全局搜索 🔍
- 输入即搜；每条 = 小标签（**统一两字**：计划=蓝/日记=绿/体系=橙，宽度贴合文字）+ 日期·类型（如 `2026-08-19 · 总结`）+ 包含关键词的**整句**（命中黄底高亮，最多两行）
- 点结果 → 跳到该页该句（计划/日记切日期定位、文字框**自动选中搜索词**；体系自动展开路径），右下角「← 返回搜索」
- 点搜索框/结果**之外** → 跳最近点过的结果（没点过跳第一条）并**收起搜索**；搜索词与结果保留，再开 🔍 仍在

## 六、技术架构

| 层 | 选型 |
|---|---|
| 桌面 | Electron 33（Chromium + Node） |
| 界面 | React 18 + Vite 5（JSX） |
| 存储 | JSON 单文件：`%APPDATA%\个人体系\data\tixi-data.json`（备份此文件即可） |
| 库 | marked + dompurify（Markdown）；lunar-javascript（农历/节日/节气）；docx（导出）；electron-builder（打包） |
| 打包 | portable 单文件 exe；`signAndEditExecutable:false`（跳过签名，规避 winCodeSign 符号链接权限问题） |

目录：`C:\Users\lenovo\体系\` 下——需求文档.md / 架构设计.md / 使用说明.md / 项目交接文档.md/.txt / 个人体系.exe（日常用，桌面有快捷方式）/ `app\` 源码。

数据模型：`settings / columns / routines / systems[{id,parentId,title,content,createdAt,updatedAt}] / events[{date:[{id,name,start,end,location,notes}]}] / days[{date:{routine,lists,reading,summary,tomorrow,diary{music,weather,events,thoughts,mood,essays}}}]`

命令（app 目录，一律 `npm.cmd`）：`build`（vite 构建）/ `start`（electron 运行）/ `app`（构建+运行）/ `dist`（打包 exe）。

开发环境注意：npm 用 `npm.cmd`（PS 执行策略禁 .ps1）；npm 11 需 `approve-scripts electron esbuild`；镜像 `registry.npmmirror.com` + `ELECTRON_MIRROR`/`ELECTRON_BUILDER_BINARIES_MIRROR`；npm/Electron 缓存指到工作区内（如 `C:\Users\lenovo\体系\.npm-cache`）；数据文件 UTF-8；沙箱内构建/安装需完整权限（用户本机运行不受影响）。

## 七、已解决的关键问题（防重复踩坑）

- 体系「编辑/移动用不了」→ 编辑框只在展开时渲染；已改为点按钮自动展开
- 搜索「标签占满整行」→ snippet 的 `-webkit-box/line-clamp` 破坏 flex 布局（实测标签 718px）；已改为 meta 包裹 + max-height 截断
- 标签被拉伸 94px → 改 `display:inline-flex` 贴合文字（实测 32px）
- 体系搜索跳转空白 → tab 代号 'system' 应为 'systems'
- 切页签丢编辑状态 → 所有页面常驻挂载（`.pagewrap.hidden`）
- 打包失败 → winCodeSign 解压需符号链接权限，`signAndEditExecutable:false` 绕过
- 搜索词选中 → 跳转后对 textarea 用 `setSelectionRange` 选中命中文字
